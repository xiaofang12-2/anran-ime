# 黯然输入法（iOS）· SVIP 纯本地版

iOS 第三方输入法。26 键拼音 + 模糊音纠错 + 上屏联想 + 用户词频学习，
手感对标百度 / 微信输入法。布局尺寸、自定义短语可在主程序里自己调。

> 名字、Bundle ID（`com.anran.ime`）都是占位的，定了正式名一次替换即可。

## v0.9.62 起：纯本地，零账号

- **没有账号、密码、手机号、登录、授权、心跳、配对码、证书固定**
- **不连任何服务器**：主 App 与键盘扩展都不发起任何网络请求（`Info.plist` 的 ATS 只保留 `NSAllowsLocalNetworking` 本机回环）
- 账号体系相关源码已整体移除（`AnRanAPI` / `AuthStore` / `PhoneStore` / `Hardening` / `SnapshotReport` / Admin App / `server.crt`）
- 主 App 与键盘的数据同步只走本机：Darwin 通知当门铃 + 回环 TCP（127.0.0.1）当数据路
- 冷启动、以及从后台重新打开时播放「欢迎尊贵的 SVIP 贵宾」黑金开场动画；整体黑金豪华主题
- 不需要下载站、不需要联网激活、不需要「完全访问」来联网

## 怎么装（免费，不用付费开发者账号）

同一个 ipa 两条路，按手机系统版本选：

| 方式 | 适用系统 | 特点 |
|---|---|---|
| 巨魔商店 TrollStore | iOS 15.0 ~ 16.6.1、17.0（机型对得上才行） | 装上永久有效，不用续签，共享容器可用 |
| 电脑自签 Sideloadly | iOS 15 及以上全部版本 | 电脑装一次，之后每 7 天续签一次 |

ipa 由云 Mac（GitHub Actions）编译产出，**未签名**，直接拿本地文件签名侧载即可，
全程不经过服务器、不需要账号。

装完启用：设置 → 通用 → 键盘 → 键盘 → 添加新键盘 → 选「黯然输入法」→ 打开「完全访问」
（只为本机回环同步与用户词典落盘，不涉及任何外网请求）。

## 主 App 与键盘怎么同步（纯本地）

1. 主 App 改动设置 / 自定义短语 / 思想库 → 写共享数据，回环 TCP server 备好整包
2. Darwin 通知当门铃，键盘收到后连 `127.0.0.1` 拉整包落盘，几十毫秒生效，开着键盘也生效
3. 主 App 里也可点「立即同步到键盘」手动触发
4. 两条路共用 `appliedKey` 去重，谁先到都不重复落盘
5. 不碰剪贴板、不经过服务器、无配对码、无登录态

## 为什么本地编不了

iOS 的编译、签名、真机安装必须走 macOS 的 Xcode。开发机是 Windows，所以：

- **源码在这里写**
- **编译交给云 Mac**（GitHub Actions 的 `macos-15` runner，配置见 `.github/workflows/ios.yml`）
- **签名交给用户手机那头**（巨魔商店 / Sideloadly 都会重新签）

## 阶段 0 验收（当前阶段）

1. 云端 CI 跑通，产出未签名 `AnRanIME.ipa`
2. 签名侧载装进 iPhone（巨魔商店 或 Sideloadly）
3. 打开「黯然输入法」→ 看到 SVIP 开场动画 → 直接进设置首页，无任何登录墙
4. 设置 → 通用 → 键盘 → 键盘 → 添加新键盘 → 选「黯然输入法」
5. 点进「黯然输入法」→ 打开「完全访问」
6. 任意输入框能弹出键盘、能敲拼音出中文候选、候选可选字上屏
7. 主 App 改设置后键盘几十毫秒内生效（本机回环同步）

## 关键约束（写代码前先看）

- **键盘扩展内存只有 30~60MB**，超了被系统静默杀掉，键盘直接消失且无崩溃日志。词库必须按需加载，不能全量塞内存
- **App Group 用不了**（免费账号自签限制），所以主 App 与键盘靠回环 TCP + Darwin 通知同步，全程不出本机
- **读不到其他 app 的内容**，所以 Windows 版那套截屏 OCR 自动怼在 iOS 上做不了
- **剪贴板能读但会弹系统确认**，挡不掉
- **键盘必须用户手动在设置里启用**，这步苹果不给自动化
- **免费 Apple ID 一个证书 7 天、同时最多 3 个 App**，所以走自签那条约 7 天续一次

### 阶段 1.5 已落地的输入体验

- **26 键**：字母 / 数字 / 符号三层，靠底行「123」「ABC」「#+=」互切，数字功能内置在布局里
- **模糊音**：zh/z、ch/c、sh/s、前后鼻音、n/l 自动容错（百度默认档，f/h、l/r 全开会灌爆候选栏，不跟），原串永远排最前
- **用户词频**：选过的词落盘，同拼音下次自动往前提；打在半路上（niha）就召回学过的整词（nihao→你好）
- **智能造词**：连续选字拼词（人+工+智+能 → 人工智能）自动学进用户词典，下次同拼音整词顶前排
- **模糊音实时生效**：开关切换后主力引擎（librime）立即容错 —— 合并层按百度默认档规则生成输入变体补查
- **智能纠错提前**：librime 候选稀薄时即掺入手滑纠正（相邻键替换/打反/多键/漏键）
- **双拼**：小鹤 / 微软 / 搜狗 / 自然码 / 紫光 / 智能ABC / 加加 七套方案，设置里一键切换；
  键位表由 tools/gen_shuangpin.py 执行 rime-ice 官方 schema 的 algebra 生成（不手抄），
  零声母同时收录官方标准码与 rime algebra 产物（爱=ai/ad、昂=ah/aah）
- **词库扩充**：热词表进构建（2024-2026 时代新词 / 网络热词 / 微信聊天口癖），
  经典入口词（你好/谢谢/什么/怎么）座次不受影响
- **上下文重排**：上屏词 → 当前候选按「你自己的搭配 + 通用字级接续」加权；搭配奖励随次数递减，偶然连打不霸榜
- **秒同步**：主 app 改设置/自定义短语/思想库，键盘几十毫秒内落盘刷新，开着键盘也生效。
  通道：Darwin 通知当门铃 + 主 app 回环 TCP（127.0.0.1）当数据路，整包直连拉取，不碰剪贴板、不经过服务器
  （App Group 用不了——免费账号自签限制）。v0.9.62 起服务端推送链路已整体移除，只保留本机回环
- **上屏联想**：上完一个字立刻按「字 -> 常用后继字」表接下一个字（`assoc.bin`）；PlumLite 记忆层参与候选排序
- **自定义短语**：打触发码直接出整段内容，主程序「自定义短语」页里增删改
- **可调布局**：键高 / 间距 / 圆角 / 字号 / 边距都能在主程序「键盘布局」页拖滑杆，实时预览
- **中英混输**：候选栏末尾永远留着原拼音串，想直接上屏英文点它就行
- **手感**：键帽白底 + 1px 投影、按下变灰缩放并带回弹动画、字母键弹气泡、扣字按键音、
  字母键上滑直接打数字、退格上滑清整串、空格左右滑挪光标、退格按住连删
