# 黯然输入法（iOS）

iOS 第三方输入法。26 键拼音 + 模糊音纠错 + 上屏联想 + 用户词频学习，
手感对标百度输入法。布局尺寸、自定义短语可在主程序里自己调。

> 名字、Bundle ID（`com.anran.ime`）都是占位的，定了正式名一次替换即可。

## 怎么装（免费，不用付费开发者账号）

同一个 ipa 两条路，按手机系统版本选：

| 方式 | 适用系统 | 特点 |
|---|---|---|
| 巨魔商店 TrollStore | iOS 15.0 ~ 16.6.1、17.0（机型对得上才行） | 装上永久有效，不用续签，共享容器可用 |
| 电脑自签 Sideloadly | iOS 15 及以上全部版本 | 电脑装一次，之后每 7 天续签一次 |

ipa 由云 Mac 编译产出，上传到下载站的「苹果手机」区，用户自己选路装。
两条路的图文指引都写在下载站里，不用另外发教程。

## 账号

跟电脑端同一套账号体系，作者在后台建号，用户在 app 里登录：

- 登录成功后票据存本地，键盘靠心跳（`/api/heartbeat`）续期
- 一个账号最多绑一台电脑 + 一台手机，换机要在后台按设备解绑
- 账号被禁用 / 解绑 / 到期后，键盘下一次心跳就失效，退回「未授权」面板
- 服务端地址写死在 `Sources/Shared/AnRanAPI.swift`（`https://47.76.120.53`）
- 自签证书靠 **证书固定** 兜底：只认打包进来的 `Support/server.crt`

### 键盘怎么拿到登录态（配对码）

主 app 与键盘扩展各自一个沙盒，登录态不走剪贴板，走服务器中转：

1. 主 app 登录后点「同步数据」——服务端看这个账号有没有**活跃的键盘会话**
   （24h 内拉过配置 / 心跳过；配对成功也会登记）
2. 没有 → 弹 6 位配对码；键盘在「未授权」面板输一次，领到票据，**一次配对永久自动同步**
3. 有 → 静默把全量配置推上服务器（布局 / 自定义短语 / 输入设置 / 思想库），
   键盘每次弹出自动拉取，改动即生效
4. 换手机 / 重装键盘 / 键盘显示「未授权」时，点「同步数据」下方的
   **「重新配对键盘」**直接出新码（长按「同步数据」也可以）

> 历史教训：配对状态早年用「有没有配对记录」判定，一次配对终身有效——
> 键盘重装丢票后服务端无从知晓，主程序永远不再出码，键盘卡死未授权。
> 现改为活跃会话判定：键盘丢票后拉不了配置，会话过期，码自然重新出现。

## 为什么本地编不了

iOS 的编译、签名、真机安装必须走 macOS 的 Xcode。开发机是 Windows，所以：

- **源码在这里写**
- **编译交给云 Mac**（GitHub Actions 的 `macos-latest` runner，配置见 `.github/workflows/ios.yml`）
- **签名交给用户手机那头**（巨魔商店 / Sideloadly 都会重新签）

## 阶段 0 验收（当前阶段）

目标：**证明整条链路通**，功能只有「能登录 + 能弹出 + 能敲英文字母」。

1. 云端 CI 跑通，产出 `AnRanIME.ipa`
2. 按下载站的指引装进 iPhone（巨魔商店 或 Sideloadly）
3. 打开「黯然输入法」→ 登录作者发的账号，看到「登录成功，已绑定本机」
4. 设置 → 通用 → 键盘 → 键盘 → 添加新键盘 → 选「黯然输入法」
5. 点进「黯然输入法」→ 打开「完全访问」
6. 任意输入框能弹出键盘、能敲英文字母
7. 主 app 里点「同步登录状态到键盘」，键盘上点「接取登录」，键盘从「未授权」变成正常键盘

## 关键约束（写代码前先看）

- **键盘扩展内存只有 30~60MB**，超了被系统静默杀掉，键盘直接消失且无崩溃日志。词库必须按需加载，不能全量塞内存
- **默认沙盒禁网**，且和主 app 隔离。要联网做心跳必须让用户开「完全访问」
- **读不到其他 app 的内容**，所以 Windows 版那套截屏 OCR 自动怼在 iOS 上做不了
- **剪贴板能读但会弹系统确认**，挡不掉
- **键盘必须用户手动在设置里启用**，这步苹果不给自动化
- **免费 Apple ID 一个证书 7 天、同时最多 3 个 App**，所以走自签那条约 7 天续一次

### 阶段 1.5 已落地的输入体验

- **26 键**：字母 / 数字 / 符号三层，靠底行「123」「ABC」「#+=」互切，数字功能内置在布局里
- **模糊音**：zh/z、ch/c、sh/s、前后鼻音、n/l 自动容错（百度默认档，f/h、l/r 全开会灌爆候选栏，不跟），原串永远排最前
- **用户词频**：选过的词落盘，同拼音下次自动往前提；打在半路上（niha）就召回学过的整词（nihao→你好）
- **智能造词**：连续选字拼词（人+工+智+能 → 人工智能）自动学进用户词典，下次同拼音整词顶前排（对标百度「选字成词」）
- **模糊音实时生效**：开关切换后主力引擎（librime）立即容错 —— 合并层按百度默认档规则生成输入变体补查，不再只有自研兜底层吃模糊音
- **智能纠错提前**：librime 候选稀薄时即掺入手滑纠正（相邻键替换/打反/多键/漏键），不用等自研兜底
- **双拼**：小鹤 / 微软 / 搜狗 / 自然码 / 紫光 / 智能ABC / 加加 七套方案，设置里一键切换；
  键位表由 tools/gen_shuangpin.py 执行 rime-ice 官方 schema 的 algebra 生成（不手抄），
  零声母同时收录官方标准码与 rime algebra 产物（爱=ai/ad、昂=ah/aah），
  搜狗/百度/QQ 与 rime 两拨用户的肌肉记忆都能用；模糊音/纠错/简拼/造词对双拼原样生效
- **词库扩充**：热词表进构建（2024-2026 时代新词 / 网络热词 / 微信聊天口癖，
  rime-ice 与 jieba 都是 2023 年前冻结的语料，打不出的「大模型/提示词/破防/躺平/干饭」全部钉到同拼音首位），
  经典入口词（你好/谢谢/什么/怎么）座次不受影响
- **上下文重排**：上屏词 → 当前候选按「你自己的搭配 + 通用字级接续」加权，打完「今天」打 tianqi，「天气」顶前排（对标百度越用越懂你）；搭配奖励随次数递减，偶然连打不霸榜
- **秒同步**：主 app 改设置/自定义短语/思想库，键盘几十毫秒内落盘刷新，开着键盘也生效，不用收起重弹、不用点「同步数据」。
  通道：Darwin 通知当门铃 + 主 app 回环 TCP（127.0.0.1）当数据路，整包直连拉取，不碰剪贴板、不经过服务器（App Group 用不了——免费账号自签限制；服务器整包推送原样保留，管多设备兜底），
  两条路共用 appliedKey 去重，谁先到都不重复落盘
- **上屏联想**：上完一个字立刻按「字 -> 常用后继字」表接下一个字（`assoc.bin`）
- **自定义短语**：打触发码直接出整段内容，主程序「自定义短语」页里增删改
- **可调布局**：键高 / 间距 / 圆角 / 字号 / 边距都能在主程序「键盘布局」页拖滑杆，实时预览
- **中英混输**：候选栏末尾永远留着原拼音串，想直接上屏英文点它就行
- **手感**：键帽白底 + 1px 投影、按下变灰缩放、字母键弹气泡、扣字按键音、
  字母键上滑直接打数字、退格上滑清整串、空格左右滑挪光标、退格按住连删
